The matter before the board

Director reports

Each director scores the matter against its own mandate only. They do not moderate themselves to agree with each other — where two directors reach opposite conclusions from the same facts, that disagreement is the finding, and you will see it argued out on the ⚔️ Debate page.

AI mode

Everything else in this file runs offline on a scoring engine you can read. This page is the optional other half: hand the same brief to a language model and let the directors speak in prose. Two ways to do it — one needs no key at all.

1 · Copy the prompt no key needed

This builds the complete board prompt with your brief and your numbers already in it. Paste it into ChatGPT, Claude, Gemini, Copilot — anything. This is also the file you would sell as a prompt product or load into a custom GPT. 

Press “Build the board prompt”.

2 · Live directors your own API key

Calls the provider directly from this page. The key is stored in this browser only and is sent to nobody but the provider you choose. There is no server in this product to send it to. Costs land on your own account.

Browser calls can be blocked. Some providers refuse requests made directly from a web page (CORS), and some corporate networks block them too. If the live run fails, the copy-the-prompt route above always works. Anthropic requires you to opt in to direct browser access; this page sends that header for you.

CLEAR AI Board of Directors

What this is. A scoring and deliberation engine, not an oracle. It applies a fixed set of rules — which you can read in this file — to figures you supply. Its confidence score measures how much the seats agree and how good your inputs are. It cannot measure whether you are right.

What it is not. Not financial, legal, tax or investment advice, and not a substitute for a real board, an accountant or a lawyer. Decisions involving other people's money, regulated activity or debt should be checked by someone qualified and accountable.
