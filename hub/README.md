# Learning apps hub

A one-page launcher for everything in this repo that someone can actually open and use.

Open `index.html` in any browser. It links to each app with a short description of what
it does, which chapters it came from, and what it needs to run — the offline HTML apps
open directly from the page, and the two that need setup (the Next.js academy and the
custom GPT) link to their guides.

Single file, no dependencies, no network. Add a card when you add an app.
