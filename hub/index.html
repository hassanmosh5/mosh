CLEAR AI Board of Directors

15 director seats · the CLEAR framework as a decision engine

Put a real decision in front of fifteen directors. Each one scores it against its own mandate using your numbers — unit economics, capacity, runway, market — then they argue, the downside gets simulated month by month for three years, and the board returns a verdict that is allowed to be “no”. Every figure you enter is tagged measured, estimated or guessed, and the confidence score is discounted accordingly. Ships with an agent pack that turns the same board into a custom GPT or Claude Project.

How to run these

  • The e-book, launch kit, prompt generator and workbook are single HTML files. Open one in any modern browser — no install, no build step, no accounts, no network. Everything you type or save stays in that browser's local storage; nothing is uploaded.
  • The academy is a real Next.js app. Follow the root README: npm install, set DATABASE_URL, then npm run db:migrate, npm run db:seed and npm run dev.
  • The e-book is generated from prisma/seed-data.ts — the same content that seeds the academy's database. Edit the seed data or ebook/template.html and re-run npm run ebook:build.
